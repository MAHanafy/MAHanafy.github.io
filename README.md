# MAHanafy.github.io

Personal academic website of Mohamed A. Hanafy. Plain HTML and CSS, hosted free on GitHub Pages.

## Publish (about 5 minutes)

1. Sign in to GitHub and create a new **public** repository named exactly `MAHanafy.github.io`.
2. On the new repo page, click **uploading an existing file**, drag in `index.html`, `style.css`, `README.md` and the `images` folder, then click **Commit changes**.
3. Go to **Settings > Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, and Save.
4. After 1 to 2 minutes the site is live at https://mahanafy.github.io

## Personalize

- **Photo:** add `images/profile.jpg` (square, about 400x400). Until then the GitHub avatar is shown.
- **CV:** add `cv.pdf` in the root folder (the CV button links to it).
- **Scholar / LinkedIn:** uncomment the two buttons in `index.html` and paste your links.
- **New papers:** copy a `<li>` block in the Publications section.
- **News:** add a `<li>` line in the News section.

## Custom domain later

Buy the domain (Porkbun or Cloudflare), then in **Settings > Pages > Custom domain** enter it and follow GitHub's DNS instructions.
